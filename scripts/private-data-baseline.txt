# Accepted strings for scripts/scan-private-data.sh
#
# Every line is an exact string that the scanner would otherwise report: a home
# directory, or a path under ~. Listing it here is a statement that it
# is documentation or test data and is safe to publish. Anything NOT listed here
# blocks the push, which is the point - a path or address nobody has accepted
# before should never reach a public tag by accident.
#
# Adding a line is a deliberate act. Say in the commit message why the string is
# safe. Secret material (keys, tokens) can never be accepted here: the scanner
# reports it whether or not it appears in this file.
#
# Regenerate the candidate list with: scripts/scan-private-data.sh --baseline
